# Instrucciones

1. Abrir el proyecto en Unity.
2. Abrir la escena principal y presionar **Play**.
3. Usar **clic izquierdo** para disparar.

## Proyectil
El proyectil se dispara en la dirección del jugador y hereda su velocidad horizontal. Al impactar con un enemigo le causa daño.

## Plataforma móvil
La plataforma se mueve automáticamente entre dos puntos. Al subir sobre ella, el jugador se mueve junto con la plataforma.
