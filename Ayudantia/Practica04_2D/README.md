# Práctica 04 - Movimiento, Animaciones y Audio

Para ejecutar el proyecto, abrir la escena correspondiente en Unity y presionar el botón **Play**.

El personaje puede moverse horizontalmente con las teclas **A/D** o **Flechas izquierda/derecha**, y saltar con **Espacio**.

Durante la demostración se puede observar:
Movimiento horizontal y desaceleración, animaciones de Idle, Walk, Jump y Fall, sonido de salto al saltar,sonido de pasos al caminar sobre el suelo.
